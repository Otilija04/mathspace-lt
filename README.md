# MathSpace LT

Create a polished, responsive, production-ready Lithuanian-language marketing website for MathSpace LT, an independent online tutor offering mathematics and physics to grades 5–12 (PUPP/VBE), university linear algebra (matrices, determinants, ranks, inverses, Gaussian elimination, linear systems, vectors, eigenvalues), calculus (limits, derivatives, partial derivatives, extrema, integrals), statistics (descriptive, hypothesis tests, p-values, confidence intervals, t-tests, ANOVA, chi-square, correlation, linear/logistic regression), Excel beginner and advanced (IF, SUMIFS, COUNTIFS, XLOOKUP, pivot tables), and statistical guidance for bachelor/master students (ethical teaching, not ghostwriting). Sections: hero, service cards, detailed expandable curriculum, about tutor (Vilnius University Mathematics bachelor's, private teaching experience since 2022, clinical statistical analysis experience; don't invent credentials), how online lessons work, FAQ, clear inquiry CTA, contact form that works only if backend configured; otherwise mailto/contact via Facebook MathSpace LT and explain configuration. Elegant editorial design, cream/navy/soft lavender, accessible, SEO, mobile friendly, strong Lithuanian copy. Avoid invented testimonials, prices, photos or personal name; use editable placeholders for contact email, price and photo. No fake working booking/payment. Make domain connection straightforward.
